# StickerYap

Android'de yeşil ekran videolarını Telegram video sticker formatına dönüştüren küçük, offline uygulama.

- 512×512 VP9 WebM
- Şeffaf arka plan
- 3 saniye altı
- 256 KB hedef boyut
- Yeşil temizleme ve kenar temizleme ayarları
- Çıktıyı Downloads/StickerYap klasörüne kaydeder

APK, GitHub Actions üzerinden otomatik derlenir.
